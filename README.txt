田中まこと（田中允）公式ホームページ 試作版

内容
- index.html：レスポンシブWebサイト本体
- assets/tanaka-portrait.jpeg：ご提供の顔写真
- assets/business-card.png：ご提供の名刺画像
- assets/design-reference.png：デザイン参考画像（含まれる場合）

使い方
1. ZIPを解凍します。
2. tanaka_websiteフォルダ内の index.html をブラウザで開きます。
3. assetsフォルダは index.html と同じフォルダ構成のまま保ってください。

実装済み
- PC・スマートフォン向けレスポンシブ表示
- スマートフォンのナビゲーションメニュー
- 年度別一般質問タブ（令和5〜8年）
- 電話番号のタップ発信リンク
- 筑紫野市議会会議録検索・議会中継へのリンク

公開前の確認事項
- 一般質問・委員会・視察内容は提供情報をもとに要約しています。公開前に公式記録との照合をお願いします。
- 生年月日、現任期、現在の役職は未掲載です。確認できる正式情報をご用意ください。
- サイト公開用のドメイン・サーバー設定は含まれていません。

議会活動の自動更新（GitHub Actions）
- 議会活動の自動更新（毎週月曜 9:13）: 議会中継の一般質問と委員会会議録を取得し、ページを更新します。
- 過去の議会活動の収集（手動実行）: 会議録検索システム（平成16年〜）と一般質問通告書（平成26年〜）から
  過去の記録を集め、data/history.json に保存します。通常は再実行不要です。
  会議録から取得し直す場合は data/history_raw.json を削除してから実行してください。
- ページは index.html の <!--AUTO:...--> の範囲が自動で書き換わります。この範囲は手で編集しないでください。
- 平成3年〜平成15年の会議録はインターネット未公開のため掲載していません。
